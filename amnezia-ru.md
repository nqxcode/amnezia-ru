# Фильтр российских IP для AmneziaWG

Установщик размещает файлы на VPS. Действующие правила nftables находятся в сетевом пространстве контейнера `amnezia-awg2`. В таблице `inet amnezia_ru` цепочка `forward` отклоняет пакеты с интерфейса `awg0`, если IP назначения входит в набор `ru4` (IPv4) или `ru6` (IPv6).

## Файлы на VPS

| Полный путь | Назначение |
| --- | --- |
| `/usr/local/sbin/amnezia-ru-restore` | Рабочий скрипт. Восстанавливает фильтр из файла, а с аргументом `update` скачивает списки IPdeny и применяет новые правила. |
| `/etc/amnezia-ru.nft` | Сохранённые правила nftables вместе с обоими списками подсетей. Файл обновляется после успешного применения правил. |
| `/etc/systemd/system/amnezia-ru.service` | Служба восстановления. Проверяет цепочку `forward` и при её отсутствии загружает сохранённые правила. |
| `/etc/systemd/system/amnezia-ru.timer` | Запускает проверку примерно каждые 10 секунд. Так фильтр возвращается после перезапуска контейнера. |
| `/etc/systemd/system/amnezia-ru-update.service` | Служба обновления. Запускает рабочий скрипт с аргументом `update`. |
| `/etc/systemd/system/amnezia-ru-update.timer` | Запускает обновление раз в сутки по времени VPS. |
| `/etc/systemd/system/timers.target.wants/amnezia-ru.timer` | Символическая ссылка для автозапуска таймера восстановления. |
| `/etc/systemd/system/timers.target.wants/amnezia-ru-update.timer` | Символическая ссылка для автозапуска таймера обновления. |
| `/var/lib/systemd/timers/stamp-amnezia-ru-update.timer` | Отметка последнего срабатывания суточного таймера. По ней systemd определяет, был ли пропущен запуск. |
| `/run/lock/amnezia-ru.lock` | Обновление и восстановление используют этот файл, чтобы не менять правила одновременно. |

**Временные каталоги.** Установщик собирает скрипт и файлы systemd в `/usr/local/sbin/.amnezia-ru.XXXXXX/`. При проверке или обновлении скачанные списки `ru4`, `ru6` и новый `filter.nft` помещаются в `/etc/.amnezia-ru.XXXXXX/`. Вместо `XXXXXX` подставляется случайный суффикс. При штатном завершении каталоги удаляются.

## Установщик и удаление

Если установщик сохранён по инструкции, его копия находится в `/root/amnezia-ru-autoupdate.sh`. Чтобы удалить фильтр, открой каталог со скачанным скриптом удаления и выполни команду под `root`.

```sh
sh amnezia-ru-uninstall.sh
```

Скрипт останавливает службы и таймеры, удаляет перечисленные постоянные файлы, файл блокировки и копию установщика в `/root`. Затем выполни `reboot` в удобное время. После перезагрузки исчезнет и таблица фильтра в контейнере.
