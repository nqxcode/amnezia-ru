# amnezia-ru

Фильтр российских IP для AmneziaWG. Блокирует трафик с интерфейса `awg0`
к российским IPv4- и IPv6-подсетям из списков IPdeny в контейнере `amnezia-awg2`.
Правила nftables применяются в сетевом пространстве контейнера.

Списки обновляются раз в сутки по времени VPS. Отдельный таймер примерно
каждые 10 секунд проверяет наличие цепочки фильтра и восстанавливает её
из сохранённого файла после перезапуска контейнера. До восстановления
фильтра блокировка отсутствует.

## Требования

- VPS с Linux, Docker и systemd; команды выполняются от `root`.
- Запущенный контейнер `amnezia-awg2` с отдельным сетевым пространством
  и VPN-интерфейсом `awg0`.
- Команды `docker`, `nsenter`, `nft`, `curl`, `flock` и стандартные утилиты shell.
- Доступ с VPS к IPdeny для загрузки обоих списков подсетей.

## Проверка и установка

Скопируй файлы `amnezia-ru-autoupdate.sh` и `amnezia-ru-uninstall.sh`
из этого репозитория в `/root` на VPS. Следующие команды выполняй на VPS.

Сначала проверь загрузку списков и совместимость правил с nftables:

```sh
cd /root
sh amnezia-ru-autoupdate.sh --check
```

Проверка скачивает списки и запускает `nft -c` в сетевом пространстве
контейнера, не применяя новые правила и не устанавливая службы.

После успешной проверки установи фильтр:

```sh
sh amnezia-ru-autoupdate.sh
```

Установщик применяет правила, сохраняет их в `/etc/amnezia-ru.nft`
и включает таймеры восстановления и ежедневного обновления.

## Управление

Посмотреть таймеры и журнал обновлений:

```sh
systemctl list-timers --all 'amnezia-ru*' --no-pager
journalctl -u amnezia-ru-update.service -n 50 --no-pager
```

Обновить списки вручную:

```sh
systemctl start amnezia-ru-update.service
```

Посмотреть действующие правила и счётчики пакетов:

```sh
netns=$(docker inspect -f '{{.NetworkSettings.SandboxKey}}' amnezia-awg2)
nsenter --net="$netns" -- nft list table inet amnezia_ru
```

## Удаление

```sh
cd /root
sh amnezia-ru-uninstall.sh
reboot
```

Скрипт удаляет службы, таймеры и сохранённые файлы. Действующий фильтр
остаётся в контейнере до перезагрузки VPS. Команда `reboot` перезагрузит VPS
и прервёт текущие подключения.

Подробное описание файлов на VPS — в [amnezia-ru.md](amnezia-ru.md).
